# XylemJS Templates

This repository contains templates for XylemJS based project.

## Usage

1. Download any one of the templates using [degit](https://www.npmjs.com/package/degit).

	To use **JavaScript** template:

	```
	npx degit xylem-js/templates/js my-xylem-js-project
	```

	To use **TypeScript** template:

	```
	npx degit xylem-js/templates/ts my-xylem-js-project
	```

1. Go to the project directory:

	```
	cd my-xylem-js-project
	```

1. Install npm dependencies:
	```
	npm install
	```
